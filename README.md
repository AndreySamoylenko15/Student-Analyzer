# 🎓 Student Analyzer (Python)

Консольний застосунок для аналізу даних про студентів.

## 🚀 Можливості

Програма дозволяє:

* 📊 Аналізувати введені дані
* 🔢 Виконувати підрахунки (середнє, кількість тощо)
* 📈 Отримувати базову статистику
* 🧮 Працювати з числовими значеннями

---

## 🛠 Як запустити

1. Встанови Python 3
2. Запусти програму:

```bash
python student_analyzer.py
```

---

## 📌 Приклад використання

```
Enter data: 10 20 30 40

1 - Average
2 - Max
3 - Min

Choose option: 1
Average: 25
```

## ⚠️ Обмеження

* Простий консольний інтерфейс
* Дані вводяться вручну
